**GodRect** - Полностью бесплатное расширение для Adobe After Effects, созданное для упрощения создания фигур с нестандартными параметрами углов, так как в чистом AE базово есть только скругление. Так же в чистом ае нет возможности создавать сетки из фигур находящихся на отдельных слоях (Такая опция в чистом АЕ есть только если все фигуры находятся внутри одного слоя). Расширение позволяет быстро размещать эти фигуры по динамической сетке в виде отдельных слоёв, Это важно для управления объектами в 3D-пространстве, так как фигуры, сгруппированные внутри одного стандартного шейпового слоя, не могут иметь индивидуальных 3D-параметров.

---

## ✨ Основные возможности

- **🔲 Продвинутые стили углов:** 
    - Мгновенное создание фигур со сглаженными *скошенными* (Beveled под 45°) или *вогнутыми* (Concave) углами.
    
    - Форма генерируется с помощью процедурной векторной математики и фильтров смещения (Offset). 
    
    - Фигуры остаются базовыми параметрическими объектами (без конвертации в векторные пути), что сохраняет их полную редактируемость.
   
    - Опциональное добавление настраиваемой внешней обводки (Stroke).
    
- **⚡ Умная сетка (Smart Grid):**
  - Создание и автовыравнивание динамической сетки копий фигур. Полностью редактируемо на лету за счет привязки через выражения (expressions).

  - Система сделана таким образом, что сетку можно продолжать редактировать ползунками (Sliders) даже без использования расширения.В

  - Возможность добавлять новые фигуры в сетку просто за счет копирования последней фигуры через Ctrl + D + [ , скопированные фигуры автоматически выставляются по динамической сетке. 
- **🛠️ Режим редактирования (Edit Mode):**  Позволяет производить массовое редактировоание всех фигур в группе одновременно.
  - Автоматически находит созданные через расширение фигуры в композиции и выделяет всю группу объектов.

  - Безопасное переименование групп с автоматическим обновлением выражений.

  - Изменение параметров фигур или масштабирование сетки «задним числом» с помощью кнопки **Update Features**.

  - Безопасное удаление мастер-слоя и всех связанных с ним клонов через **Kill Rects**.

## 📦 Инструкция по установке

1. Скачайте архив `GodRect vX.X.zip` из раздела [Releases](../../releases).
2. Распакуйте содержимое архива в системную папку CEP-расширений Adobe:
   - **Windows:** `C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\`
   - **macOS:** `/Library/Application Support/Adobe/CEP/extensions/`

3. **Включите режим разработчика (PlayerDebugMode):**
   Поскольку расширение не имеет официальной цифровой подписи Adobe, его необходимо разрешить в системе, иначе After Effects его заблокирует.
   * **Для Windows (Автоматический):**
   * 1. Скачайте из репозитория файл PlayerDebugMode.reg
     2. Сделайте двойной клик по файлу
     3. Ознакомтесь с предупреждением, нажмите да, либо переходите к ручному варианту

   * **Для Windows(Ручной вариант):**
     1. Нажмите комбинацию клавиш `Win + R`, введите `regedit` и нажмите `Enter`.
     2. Перейдите по пути: `HKEY_CURRENT_USER\Software\Adobe\`
     3. Найдите раздел нужной версии вашего пакета CSXS (например, `CSXS.11`, `CSXS.12` и т.д. в зависимости от версии After Effects). Если такого раздела нет, создайте его вручную.
     4. Внутри этого раздела создайте String Value с именем **`PlayerDebugMode`**.
     5. Измените его значение на **`1`**.

   * **Для macOS:**
     Откройте терминал и выполните команду (замените `11` на версию вашего пакета CSXS, если используете другой год After Effects):
     ```bash
     defaults write com.adobe.CSXS.11 PlayerDebugMode 1
     ```

4. Перезапустите After Effects и перейдите в меню: **Window > Extensions > GodRect** (Окно > Расширения > GodRect).
